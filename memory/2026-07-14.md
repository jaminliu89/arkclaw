- 每日早8点自动推送10个热门选题（cron已设置）

## 脑暴汇总的所有内容方向

### 日常高频内容（口播矩阵，每天5-10条）
1. **扎心觉醒类** — 引发共鸣，负责传播（35岁焦虑、裁员、危机感）
2. **自律方法类** — 提供价值，负责涨粉（具体可执行的方法）
3. **逆袭故事类** — 真实感，负责信任（亲身经历/身边人的故事）
4. **AI赋能类** — 差异化，负责独特性（AI工具+实际效果，融合AI博主身份）
5. **金句口播类** — 低制作成本，适合批量（15-30秒一段话）

### 系列精品内容（每周1-2条）
1. **「遇见100个人」** — 带相机遇见不同的人，拍照+讲故事
2. **「AI大厨养成记」/「AI教我做饭」** — 结合学美食的需求
3. **「AI改造计划」** — AI改造旧物/照片/房间/自己
4. **「AI帮我省了多少钱」** — 省钱类，经济下行期刚需
5. **「和AI打赌」** — 对抗性内容，天然有悬念
6. **「摄影挑战赛」** — 挑战极端条件出片
7. **「一人剧组」** — 幕后揭秘

### 直播方向
1. **AI吃播** — 边吃边分析热量+口播AI资讯
2. **户外摄影直播** — 直播拍照过程
3. **户外遇见人直播** — 遇见100个人的直播版
4. **户外美食直播** — 街边摊/夜市/菜市场

### 内容矩阵规划
```
周一    AI资讯快讯（保持AI博主标签）
周二    AI技巧干货（留粉）
周三    系列内容A（遇见100个人 / AI学做饭 隔周轮换）
周四    系列内容B（AI改造 / 省钱系列）
周五    系列C（遇见100个人 / 摄影挑战）
周末    直播日
```

## 生产流程设计
- 每天5-10条口播的流水线：提前备选题 → AI写稿 → 改稿 → 批量拍摄 → AI批量剪辑 → 分时段发布
- 系列内容：每期2-3天制作周期，踩点→拍摄→修图→剪辑→发布
