# 人格反推系统 Personality Miner

> 你不是在分析他。你是在把他自己说不清楚的东西，替他说清楚。

---

## 核心原理

一个人说不清楚自己是谁，但他说的每一句话都在暴露自己。

**这个系统做的事：**
接收一个人的自述——碎片化的、啰嗦的、自相矛盾的、边骂自己边解释的——然后输出一份结构化的人格画像。

**不是心理学诊断。是内容创作工具。**
目的是：挖出这个人身上最能做成内容的东西。

---

## 输入

接收任何形式的自述：
- 语音转文字稿
- 直播间连麦
- 聊天记录
- 日记/随笔
- 采访回答
- 甚至是一条很长的朋友圈

**不需要结构化。越碎越好。**
碎片里才有真相。修饰过的自述反而没用。

---

## 工作流程

### 第一步：提取原始素材

从自述中提取关键片段。注意这几类：

| 类型 | 标志 | 例子 |
|------|------|------|
| 事实 | 时间、地点、人物、事件 | "2018年创业失败" |
| 感受 | 我觉得、我感觉、我害怕 | "感觉像一颗沙粒" |
| 自评 | 我就是、我这人、我最大的问题是 | "我拖延、好面子、爱装逼" |
| 矛盾 | 但是、可是、然而、同时 | "我很外向但同时我又内向" |
| 意象 | 有画面感的描述 | "房间里有面白板墙" |
| 金句 | 自己说出来的总结 | "让父母老的慢一点" |

### 第二步：七维映射

将提取的素材映射到7个维度。

**维度1：童年与家庭印记**
```
关键问题：
- 谁带大的？父母做什么的？
- 童年性格：调皮/安静？外向/内向？
- 跟父母的关系？现在有变化吗？
- 童年最深的记忆是什么？

⚠️ 注意：
- 小时候"不被看见"的人，长大后特别需要认可
- 跟父母关系里藏着所有成年后的行为模式
- 父亲的角色缺失/在场，影响一生的安全感
```

**维度2：学业与智力自我认知**
```
关键问题：
- 成绩怎么样？喜欢学习吗？
- 有没有被老师/同学肯定过？
- 现在对学习什么态度？
- 会不会用学习来逃避其他事？

⚠️ 注意：
- "不爱学习但爱看书" = 用求知欲弥补学历自卑
- "买了很多书但没看完" = 用学习代替行动
- 这是最常见的逃避机制之一
```

**维度3：职业与能力轨迹**
```
关键问题：
- 做过什么工作？最长的一份多久？
- 最擅长什么？最不擅长什么？
- 高光时刻？至暗时刻？
- 如果重新选，会做什么？

⚠️ 注意：
- 职业生涯的"高光"和"坠落"之间的落差 = 核心内容素材
- "除了XX什么都不会" = 破釜沉舟的叙事基础
- 技能单一不是缺点，是专注力的证明
```

**维度4：社交与人际模式**
```
关键问题：
- 朋友多吗？怎么认识的？
- 社交中主动还是被动？
- 低谷期见人还是不见人？
- 在意别人怎么看自己吗？

⚠️ 注意：
- "把自己关在房间里" = 社交回避型逃避
- "纹身以为会有朋友" = 用外在改变弥补社交缺失
- 孤独感是最强的内容共鸣点
```

**维度5：爱情与亲密关系**
```
关键问题：
- 有过几段感情？最长多久？
- 爱情在你人生中排第几？
- 现在对爱情什么态度？
- 什么样的人会喜欢你？

⚠️ 注意：
- "不敢想，没那个资格" = 自我评估后的放弃
- 比"找不到"更痛的是"觉得自己不配"
- 这条通常不会主动说，需要挖
```

**维度6：自我认知与核心冲突**
```
关键问题：
- 用三个词形容自己
- 最大的优点和缺点是什么？
- 内心最深的恐惧是什么？
- 有没有一直在逃避的事情？

⚠️ 注意：
- 这个维度是人格的核心
- 注意他"说什么"和"没说什么"之间的差距
- 自相矛盾的地方 = 核心冲突所在
```

**维度7：驱动力与底层动机**
```
关键问题：
- 现在最想实现什么？
- 如果明天是最后一天，会做什么？
- 人生的意义是什么？
- 什么情况下你会觉得自己"值了"？

⚠️ 注意：
- 嘴上说的目标和内心真正的驱动力往往是两回事
- 真正的驱动力通常是：愧疚、恐惧、渴望被认可
- 找到那个"他不说但一直在推着他走"的东西
```

### 第三步：识别逃避机制

从自述中识别这个人的逃避模式。

| 逃避形式 | 自我欺骗的话 | 识别信号 |
|---------|------------|---------|
| 用规划代替执行 | "我在计划" | 白板墙、写满的笔记本、不断改方案 |
| 用学习代替行动 | "我在进步" | 买书不读、买课不看、收藏从未停止 |
| 用外在改变代替内在改变 | "这样我就会不一样" | 纹身、换发型、买新设备 |
| 用放松代替面对 | "我需要休息" | 打游戏、刷手机、睡觉 |
| 用自嘲代替改变 | "我就是这样的人" | 承认问题但不动，把自嘲当解药 |

**关键：逃避机制不是缺点，是内容素材。**
一个人怎么逃避，比他怎么成功更有看点。

### 第四步：输出结构化画像

#### 输出格式

```
## 一、基础画像卡（一句话总结）
[身份标签] + [核心矛盾] + [进行时的状态]
例：37岁重启的摄影师，卡在80/90后中间，用白板墙骗了自己好几年。

## 二、核心冲突（这个人的内在矛盾是什么）
[他要A但他在做B] 的落差
例：他想让父母轻松，但他每天在家做梦。

## 三、逃避机制（他用什么方式逃避问题）
列出2-3种逃避形式，每种配一个真实素材。

## 四、驱动力量（什么能真正让他动起来）
不是他嘴上说的目标。是他内心深处的恐惧或愧疚。

## 五、故事素材库（直接可用的内容选题）
从自述中提取5-8个有画面感的素材，每个标注可用角度。

## 六、内容建议（他适合做什么内容）
P0/P1/P2分级，给出具体的内容类型和标题示例。

## 七、禁忌（绝对不能踩的雷区）
- 他反感什么话？
- 什么内容会让他人设崩塌？
- 什么话题他还没准备好面对？
```

## 案例：柳俊名

完整案例见 `/Users/kimliu/Documents/柳俊名人物画像档案.md`

**一句话总结：**
37岁重启的摄影师，卡在80/90后中间，白板墙上写满了计划但一个都没执行，用买书和纹身掩饰自卑，驱动他的是"让父母老的慢一点"。

**核心素材（12个，全部来自他原话）：**
1. 白板墙——"上面写的字比我发过的视频还多"
2. 父亲——"调光圈的手变成拧螺丝的手"
3. 书——"买了几十本，一本没看完"
4. 纹身——"以为会有朋友，并没有"
5. 摆地摊——"跟妈妈去摆，觉得不好意思"
6. 自我诊断——"说空话吹牛逼忽悠家人"
7. 第一个视频——"没准备好就发了"
8. 爱情——"不敢想，没那个资格"
9. 想法散乱——"学美食/摆摊/跑滴滴/带狗旅行"
10. 打王者——"每天陷入焦虑循环"
11. 北漂——"浑浑噩噩好几年"
12. 摄影——"除了摄影什么都不会"

## 使用方式

### 快速启动

```
personality-miner 自述文本
```

直接输入自述文本，系统自动跑完七维映射+逃避识别+画像输出。

### 深度模式

```
personality-miner 自述文本 --deep
```

增加追问环节：
1. 输出初版画像
2. 针对信息不完整的维度，生成3个追问问题
3. 用追问结果补充画像

### 轻量模式

```
personality-miner 自述文本 --quick
```

只输出：一句话总结 + 核心冲突 + Top5素材
