# 街头拍摄执行SOP

## 一、出发前准备

### 设备检查清单
```
□ 相机/手机：电量100%，内存卡清空
□ 备用电池/充电宝（至少2块电池）
□ 镜头：常用焦段（35mm/50mm最适合人文）
□ 补光灯/反光板（室内/夜景必备）
□ 便携照片打印机（有的话带上，现场送一张效果翻倍）
□ 手机：用来加微信发照片
```

### 心理准备
1. **被拒绝是正常的**：10个人里有3个答应就不错了
2. **真诚最重要**：不要像查户口，就当随便聊天
3. **不预设结果**：遇到什么拍什么，没有就当散步
4. **安全第一**：偏僻的地方不要去，人多的地方拍

### 物料准备
- 小礼物：明信片/小贴纸/糖果（感谢对方配合）
- 水和纸巾：可以递给对方，拉近距离
- 名片/二维码：方便对方加你要照片

## 二、搭话话术模板

### 开场第一句（最重要）

#### 版本A：直接真诚型
> "你好，打扰一下，我是摄影博主，正在拍普通人的故事，觉得你很有感觉，能不能帮你拍几张照片？免费的，拍完发给你。"

#### 版本B：赞美切入型
> "你好，不好意思打扰了，我觉得你这个样子特别好看/特别有感觉，能不能给你拍几张照片？"

#### 版本C：场景切入型
> "你好，我在拍这个集市/这条街的故事，能不能给你拍几张？就记录一下，到时候发给你。"

#### 版本D：帮忙型
> "叔叔/阿姨，我帮您拍张照吧，您站这挺好的，拍完微信发给您。"

### 对方犹豫时
> "很快的，两分钟就好，不耽误你事。"
> "我就拍几张，你该干嘛干嘛，不用特意摆。"
> "拍不好我删掉，你放心。"

### 对方拒绝时
> "好的不好意思打扰了。"（微笑，立刻走开，不要纠缠）

## 三、聊天提问技巧

### 破冰问题（开场5分钟）
- "您这是在干嘛呢？"
- "今天天气不错/挺热的哈"
- "您经常来这吗？"
- "做这个做多久啦？"

### 深入问题（熟悉一点后）
- "做这个辛不辛苦？"
- "家里孩子多大啦？"
- "为什么想做这个呀？"
- "这么多年有没有印象特别深的事？"

### 情感问题（关系好的时候问）
- "有没有什么遗憾的事？"
- "最想的人是谁？"
- "觉得自己幸福吗？"
- "如果年轻的时候做了另一个选择，会怎么样？"

### 提问原则
1. **从浅到深**：不要一上来就问隐私问题
2. **先分享自己**：你先说一点你的事，对方才愿意说
3. **认真听**：不要打断，眼神交流，点头回应
4. **从回答里找下一个问题**：不要像背稿子
5. **对方不想说就立刻转话题**：不要追问

## 四、拍摄引导技巧

### 让对方放松
1. **先闲聊再拍**：聊几分钟熟了再掏相机
2. **不让对方看镜头**："你忙你的，我随便拍几张"
3. **边拍边聊天**：不要沉默，沉默就会紧张
4. **多夸**："对，就这样，很好看"、"特别自然"

### 常用引导语
- "你看那边就行，不用看我"
- "往前走两步，我抓拍"
- "低头做你手里的事就好"
- "笑一下，不用刻意，想到开心的事就行"
- "你平时什么样就什么样，不用摆"

### 必拍镜头清单
```
【全景】交代环境，人物在场景里
【中景】半身/大半身，看状态
【近景】脸部表情，情绪
【特写】手、眼睛、有故事的细节
【花絮】你和对方互动的画面（第三人称拍）
【看照片的反应】重点中的重点！一定要拍到
【成品】相机屏幕的特写，或者最后定格的成片
```

## 五、结束与后续

### 怎么结束
1. "好了，差不多了，谢谢你啊"
2. 给对方看几张："你看，拍得挺好的吧"
3. 加微信/留联系方式："我回去修好了发给你"
4. 再次感谢："耽误你时间了，谢谢"

### 后续跟进
1. **当天发照片**：不要拖，最好当天就发
2. **发的时候说几句话**："今天谢谢你，照片修好了，你看看喜不喜欢"
3. **可以问能不能发平台**："对了，我视频里可能会用到你的镜头，没问题吧？"
4. **不要骚扰**：发完照片就好，不要没话找话

### 发布前确认
- 人脸：对方介意就打码/用背影
- 隐私：敏感信息不要放
- 故事：对方说的私事，没经过同意不要全说
- 尊重：对方说不能发的，绝对不能发

## 六、常见问题处理

### Q：被拒绝了很尴尬怎么办？
A：太正常了，10个人有7个拒绝都是正常的。被拒绝就笑着说"没事打扰了"，立刻找下一个。越被拒绝越熟练，脸皮是练出来的。

### Q：对方很紧张，拍出来很僵怎么办？
A：先别拍了，继续聊天。聊到对方放松了，忘了你在拍照，再偷偷抓拍。或者让他做点什么事（走路、干活、看手机），动态的就自然了。

### Q：不知道聊什么，冷场了怎么办？
A：聊天气、聊环境、聊手里的东西、夸对方。实在没话说就说"我先拍几张，你忙你的"，用拍摄填补沉默。

### Q：拍出来不好看怎么办？
A：没关系，重点是故事不是颜值。真实的、有情绪的照片，比好看但空洞的照片有力量。而且你可以修，调个色就好看了。

### Q：对方问你拍这个干嘛、有什么用？
A：实话实说："我在做一个系列，记录普通人的故事，发在抖音上，让更多人看到平凡人的生活。"不用解释太多，越解释越像骗子。

## 七、新手练习计划

### 第1周：练胆子
- 目标：每天搭话5个人，不管拍不拍得到
- 重点：克服开口的恐惧
- 要求：被拒绝也没关系，开口就算完成

### 第2周：练沟通
- 目标：每天成功拍1个人
- 重点：聊天，挖故事，不只是拍照
- 要求：每个人至少聊5分钟

### 第3周：练拍摄
- 目标：每次拍够10个镜头
- 重点：画面、光影、情绪捕捉
- 要求：有全景有特写有花絮

### 第4周：练剪辑
- 目标：剪出一条完整的片子
- 重点：节奏、叙事、结尾升华
- 要求：有开头有结尾有金句

## 八、伦理红线（绝对不能碰）

1. **不消费苦难**：不要为了流量刻意拍人家惨的一面
2. **不诱导编造**：不要让对方"演"得更惨更感人
3. **尊重隐私**：不想露脸就别拍，不想说的别追问
4. **不占便宜**：不要利用对方的善良蹭流量
5. **说到做到**：说发照片就一定要发，说免费就免费
6. **平等视角**：不要居高临下的"我帮你"的姿态
7. **保护对方**：发布后如果有负面评论，要护着对方
