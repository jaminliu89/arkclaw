# 王子不会拍风格深度拆解

## 核心模式：街头摄影 + 人文关怀 + 温暖治愈

### 王子不会拍的内容公式
```
街头偶遇普通人 + 了解他们的故事 + 帮拍照/帮小忙 + 真实反应 + 泪点结尾
```

### 为什么火？
1. **善良共鸣**：每个人心里都有柔软的地方，看博主做好事会被治愈
2. **真实感强**：都是真实的陌生人，没有剧本痕迹
3. **小人物故事**：普通人的心酸和坚持，最容易共情
4. **正向价值**：传播善意，平台也喜欢推

---

## 标准结构拆解

### 开头（0-5秒）
- 一个人物背影/特写
- 一句引发好奇的旁白："这个叔叔在这站了一天了，不知道在等什么"

### 搭话（5-20秒）
- 上前搭话，闲聊开场
- 自然不刻意，像随便聊天
- 被拒绝也没关系，真实剪进去

### 了解故事（20-50秒）
- 慢慢聊，挖出背后的故事
- 不追问，对方愿意说就听
- 重点：心酸的点、坚持的点、温暖的点

### 帮忙/拍照（50秒-1分30秒）
- 提出帮拍张照，或者帮个小忙（买水、买饭）
- 拍照过程中的互动
- 对方的反应（不好意思、开心、感动）

### 看照片/反应（1分30秒-1分50秒）
- 对方看到照片的表情
- 说的话（通常很朴实但很戳人）
- 告别时的互动

### 结尾升华（1分50秒-2分）
- 照片定格
- 一句温暖的旁白
- 引发思考的字幕

## 完整脚本示例（打工父亲主题）

```
【开头 0-5s】
（音乐节后台，一个工人大叔在看舞台）
旁白："搭建舞台的大叔，站在这看了很久了。"

【搭话 5-20s】
博主走过去："叔叔，您也喜欢这个歌手啊？"
大叔不好意思笑："我女儿喜欢，我拍给她看。"
博主："您女儿多大啦？"
大叔："16了，追星追得厉害。"

【故事 20-50s】
博主："那您怎么不带她一起来啊？"
大叔："我在这干活呢，搭这个舞台。
她很小我就出来打工了，没怎么陪过她。
她生日快到了，我拍点视频回去给她看，她肯定高兴。"
（顿了顿）
"就是不知道拍得好不好，她会不会嫌我拍得丑。"

【帮忙 50s-1分20s】
博主："叔叔我是拍照的，我帮您拍几张吧，拍清楚点，您女儿肯定喜欢。"
大叔不好意思："不用不用，太麻烦你了。"
博主："没事，我正好也在拍素材，您站这我给您来一张。"
（拍照过程，大叔有点拘谨，慢慢放松）

【看照片 1分20s-1分40s】
博主把相机给大叔看。
大叔盯着看了好久，笑了："拍得真好，我都没这么精神过。
她妈要是看到，肯定又要说我乱花钱拍照片。"
（笑着，但眼睛有点红）

【结尾 1分40s-2分】
（照片定格，大叔笑得很朴实）
旁白："他搭建了无数人的舞台，
却从来没有出现在女儿的观众席里。
但爱，从来都不在舞台中央。"
字幕：你的爸爸，也在为你默默搭建舞台吗？
```

## 王子不会拍的选题方向

### 常见人物类型
1. **环卫工人**：凌晨上班、冬天很冷、默默付出
2. **外卖/快递员**：风吹日晒、赶时间、有故事
3. **工地工人**：为了家人、孩子、辛苦但乐观
4. **摆摊老人**：年纪大了还在干活、有手艺
5. **手艺人**：老手艺快失传了、坚持了几十年
6. **留守儿童**：和爷爷奶奶过、想爸爸妈妈
7. **流浪汉/拾荒者**：背后有故事、不是表面那样
8. **保安/保洁**：不起眼但重要的岗位

### 常见情感切入点
- 为了孩子/家人的付出
- 坚持了很多年的事情
- 不被理解但还在做
- 平凡但伟大的普通人
- 陌生人之间的善意

## 拍摄注意事项（人文类特别重要）

### 尊重第一
1. **不要消费苦难**：不是拍人家多惨来博流量
2. **平等视角**：不要居高临下的"施舍感"
3. **征得同意**：拍之前问，发之前再确认
4. **保护隐私**：脸不愿意露就拍背影/侧影，敏感信息打码

### 沟通技巧
1. **先帮忙再说话**：买瓶水、递根烟，拉近距离
2. **闲聊开场**：从天气、生意、手里的东西聊起
3. **认真倾听**：不要打断，眼神交流，点头回应
4. **不要追问**：对方不想说的就别问，点到为止

### 分寸感
1. **帮忙要适度**：不要给大钱，小礼物/一顿饭/一张照片就好
2. **不要演**：真心实意，观众看得出来真假
3. **不消费对方**：不要反复拍同一个人蹭流量
4. **把照片给人家**：这是最基本的，拍了就要发给对方

## 你可以借鉴的点

### 你的优势
1. **你有乡村场景**：老家有大量真实的人文素材，婆婆、邻居、赶集的人
2. **你有真实感**：你自己也是普通人、社恐、在改变，和小人物有共鸣
3. **你有技术**：拍得好，照片本身就是惊喜

### 可以做的方向
1. **乡村人物系列**：村里的手艺人、老人、留守儿童
2. **赶集系列**：集市上的各种摊主，每个人都有故事
3. **婆婆系列**：婆婆的手艺、婆婆的故事，天然有温度
4. **摆摊系列**：你自己摆摊，遇到的各种客人的故事

### 新手起步建议
1. 从身边人开始拍，婆婆、妈妈、邻居，练手
2. 不用刻意找"惨"的，平凡人的日常就很打动人
3. 重点是真诚，不是技巧
4. 每条结尾的那句话要认真写，那是灵魂
