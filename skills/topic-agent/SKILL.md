# 抖音选题生成器 — 关键词驱动模板

> 用户说行业+4个关键词+选题类型，自动输出20条口语化选题。

## 核心模板

```
用户输入模板：
「我是做[行业A]也有[行业B]的实体老板，
今天我想做抖音，我给你四个关键词：[K1]、[K2]、[K3]、[K4]，
围绕这四个关键词给我[类型1]选题、[类型2]类的、[类型3]类的、[类型4]类的，
请你口语化给我。」

→ 输出：20条口语化选题
```

## 第一步：解析用户输入

### 变量提取

| 变量 | 说明 | 例子 |
|------|------|------|
| 行业A | 主赛道 | 农村坝坝宴婚礼 |
| 行业B | 副赛道/关联赛道 | 城里酒店婚礼 |
| K1 | 关键词1 | 大概多少 |
| K2 | 关键词2 | 婚礼布置 |
| K3 | 关键词3 | 婚礼现场 |
| K4 | 关键词4 | 仪式感 |
| 类型1 | 选题类型1 | 教知识 |
| 类型2 | 选题类型2 | 揭秘类 |
| 类型3 | 选题类型3 | 避坑类 |
| 类型4 | 选题类型4 | 干货分享类 |

### 选题类型库（供用户选择或自动匹配）

| 类型 | 特征 | 典型标题开头 |
|------|------|-------------|
| 教知识 | 教具体操作、方法 | 「怎么」「如何」「3招」「1分钟学会」 |
| 揭秘类 | 爆料行业内幕 | 「老板不会告诉你的」「行业内幕」「真相」 |
| 避坑类 | 提醒别踩雷 | 「千万别」「后悔」「避开」「踩过坑」 |

| 对比类 | A vs B | 「XX和XX哪个好」「区别」「怎么选」 |
| 故事类 | 真实案例、客户故事 | 「我遇到一个客户」「真实案例」 |
| 痛点类 | 放大不解决的后果 | 「后悔」「亏了」「白花了」 |
| 种草类 | 推荐、展示效果 | 「被问爆了」「绝了」「效果惊艳」 |

## 第二步：选题生成规则

### 交叉矩阵法

每个关键词 × 每个选题类型 = 至少1条选题

```
K1 × 类型1 = 至少1条
K1 × 类型2 = 至少1条
K1 × 类型3 = 至少1条
K1 × 类型4 = 至少1条

K2 × 类型1 = 至少1条
...类推
```

这样4个关键词 × 4种类型 = 16条基础选题，再加4条延伸选题凑20条。

### 20条选题分配

| 类型 | 数量 | 说明 |
|------|------|------|
| 教知识 | 5条 | 每个关键词至少1条，多1条延伸 |
| 揭秘类 | 5条 | 每个关键词至少1条，多1条延伸 |
| 避坑类 | 5条 | 每个关键词至少1条，多1条延伸 |
| 干货分享 | 5条 | 每个关键词至少1条，多1条延伸 |

如果用户指定了其他类型组合，按比例分配。

### 口语化规则

每条选题必须符合以下口语化标准：

```
✅ 像一个人在对另一个人说话
✅ 有语气词（吧、吗、啊、了、的）
✅ 有问句、感叹句、反问句
✅ 有具体场景和画面
✅ 字数在15-30字之间

❌ 书面语、新闻体、标题党
❌ 堆砌关键词
❌ 没有具体信息
❌ 太长（超过30字）
```

### 口语化标题示例

| 书面化（❌） | 口语化（✅） |
|------------|------------|
| 「农村婚礼预算规划指南」 | 「农村办场婚礼到底要花多少钱？」 |
| 「婚礼布置技巧分享」 | 「婚礼布置千万别踩这几个坑，我替你试过了」 |
| 「仪式感对婚礼的重要性分析」 | 「婚礼没仪式感，以后想起来真的会后悔」 |
| 「酒店婚礼与农村婚礼对比研究」 | 「城里酒店婚礼和农村坝坝宴，哪个更划算？」 |

## 第四步：选题质量检查

生成的20条选题必须通过以下检查：

- [ ] 每条标题包含至少1个用户给出的关键词
- [ ] 4种选题类型各5条（或按用户要求分配）
- [ ] 全部口语化，读起来像人话
- [ ] 没有完全重复的选题方向
- [ ] 用户确实能拍出来（可执行）
- [ ] 覆盖了行业A和行业B（如果用户给了两个行业）
