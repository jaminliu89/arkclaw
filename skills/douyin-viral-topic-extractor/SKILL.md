# 抖音爆款选题提取器

> 行业实体店老板/从业者专用。说行业，自动提取同行业爆款，生成选题。

## 核心流程

```
用户说行业 → 搜索抖音100条爆款 → 提取标题选题
→ 统计高频词/高频句式 → 生成20条新爆款选题
```

---

## 第一步：搜索抖音同行业爆款内容

### 搜索入口

使用**浏览器工具**在抖音搜索框搜索。如果浏览器不可用，使用web_fetch搜索。

### 搜索关键词

根据用户行业，构造2-3组搜索词：

| 行业 | 搜索词1 | 搜索词2 | 搜索词3 |
|------|---------|---------|---------|
| 门窗 | 门窗行业 抖音 爆款 | 门窗老板 抖音 热门 | 门窗知识 抖音 |
| 餐饮 | 餐饮创业 抖音 爆款 | 餐饮老板 抖音 热门 | 餐饮行业 抖音 |
| 家居 | 家居行业 抖音 爆款 | 家居老板 抖音 热门 | 家居知识 抖音 |
| 装修 | 装修行业 抖音 爆款 | 装修公司 抖音 热门 | 装修知识 抖音 |
| 美业 | 美业 抖音 爆款 | 美容老板 抖音 热门 | 美业知识 抖音 |

### 数据采集标准

| 维度 | 要求 |
|------|------|
| 数量 | 至少100条 |
| 点赞量 | 5000以上（优先选1万+的） |
| 内容类型 | 同行业同赛道 |
| 时间范围 | 最近3-6个月 |
| 来源 | 抖音搜索结果页 |

### 采集字段

每条记录至少包含：

```
标题：视频的完整标题文字
点赞量：点赞数
（可选）评论区高频问题/用户痛点
```

## 第二步：提取标题和选题

将收集到的标题按以下维度整理：

### 选题分类

| 类别 | 特征 | 例子 |
|------|------|------|
| 干货教程 | 教你怎么做、怎么选 | 「门窗选购3个坑」 |
| 避坑指南 | 提醒你别踩雷 | 「装修门窗千万别选这种」 |
| 行业揭秘 | 爆料行业内幕 | 「门窗老板不敢告诉你的」 |
| 对比测评 | A vs B | 「断桥铝vs系统窗」 |
| 真实案例 | 前后对比 | 「3万块的门窗改造效果」 |
| 客户故事 | 客户经历 | 「客户用了5年后的真实反馈」 |
| 争议观点 | 引起讨论 | 「便宜门窗到底能不能买」 |
| 痛点放大 | 不解决的后果 | 「选错门窗后悔10年」 |

## 第三步：高频词统计分析

### 统计方法

将100条标题文本合并，提取高频词：

```
步骤：
1. 将所有标题文本合并
2. 分词（注意行业术语）
3. 统计词频，排除停用词（的、了、是等）
4. 按频率排序，取前30个高频词
5. 分类整理
```

### 高频词分类

| 词类 | 说明 | 例子 |
|------|------|------|
| **痛点词** | 用户恐惧/焦虑 | 坑、骗、后悔、误区、陷阱 |
| **利益词** | 用户想要的 | 省钱、省心、效果、对比 |
| **动作词** | 用户想做的事 | 选、买、装、换、避 |
| **数字词** | 具体量化 | 3个、5招、10年、99% |
| **情绪词** | 激发情感 | 震惊、千万别、后悔、绝了 |
| **行业词** | 赛道关键词 | 根据用户行业 |

### 高频句式统计

统计标题中重复出现的句式结构：

| 句式 | 例子 |
|------|------|
| 「XX千万别XX，否则XX」 | 「买门窗千万别图便宜，否则后悔10年」 |
| 「XX行业的XX，XX」 | 「门窗行业的5个潜规则，老板不会告诉你」 |
| 「XX了XX年才知道」 | 「做了10年门窗才知道的真相」 |
| 「XX对比XX，差距XX」 | 「300和3000的门窗，差距在哪」 |
| 「XX不XX，XX白做了」 | 「装修不装断桥铝，钱白花了」 |
| 「XX别再XX了」 | 「选门窗别再只看价格了」 |
| 「XX是XX不是XX」 | 「好门窗是选出来的不是买出来的」 |
| 「XX招搞定XX」 | 「3招搞定全屋门窗选购」 |

## 第四步：生成20条新爆款选题

### 选题生成规则

```
每条选题必须包含：
1. 核心高频词（从统计中选取）
2. 匹配的高频句式（从统计中选取）
3. 针对行业痛点（从采集的内容中提取）
```

### 20条选题分配

| 类型 | 数量 | 说明 |
|------|------|------|
| 干货教程型 | 4条 | 教具体操作 |
| 避坑警示型 | 4条 | 提醒别踩雷 |
| 行业揭秘型 | 3条 | 爆料内幕 |
| 对比测评型 | 3条 | A vs B |
| 痛点放大型 | 3条 | 不解决的后果 |
| 真实案例型 | 3条 | 前后对比/客户故事 |

### 选题格式

每条选题输出格式：

```
1. [类型] 标题文案
   选题说明：这个标题为什么能火？
   适用场景：适合什么形式（口播/情景/展示）
```

## 注意事项

### 搜索限制处理

| 问题 | 应对 |
|------|------|
| 抖音搜索不到100条 | 放宽点赞量到3000+，或扩大关键词 |
| 浏览器无法打开抖音 | 用web_fetch + 抖音视频搜索页面 |
| 页面加载不全 | 用滚动+等待加载更多 |
| 被封/被限 | 换搜索词，减少频率 |

### 行业词库构建

如果用户行业比较冷门/细分，先构建基础行业词库：

```
方法：在百度/知乎搜索「XX行业常用术语」
目的：确保搜索词覆盖行业核心关键词
```

### 选题质量检查

生成的20条选题必须通过以下检查：

- [ ] 每条标题包含至少1个高频词
- [ ] 每条标题匹配1个高频句式
- [ ] 每条标题针对具体痛点
- [ ] 不重复（20条没有完全相同的选题方向）
- [ ] 可执行（用户确实能拍出来）
- [ ] 有爆款潜力（标题本身吸引点击）
