# 直播话术生成器 — 人和行业双变量提示词模板

> 设计逻辑：从 topic-agent 和 douyin-viral-topic-extractor 的结构中提取的「变量输入→交叉生成→口语化输出」模板，应用到直播话术场景。

---

## 核心模板（用户输入格式）

```
我是[人名]，做[行业]的，
直播类型是[首播/带货/知识分享/聊天/探店/户外/才艺]，
目标受众是[受众描述]，
我的个人特点是[个人标签/风格]，
核心话题是[话题1][话题2][话题3]，
帮我写一套直播话术，要口语化，能直接上播说的。
```

### 变量解析

| 变量 | 说明 | 例子 |
|------|------|------|
| 人名 | 主播名字/账号名 | 柳俊名 / 老王门窗 |
| 行业 | 赛道/领域 | 门窗 / 餐饮 / 摄影 / 婚礼 |
| 直播类型 | 场景分类 | 首播 / 带货 / 知识分享 / 聊天 |
| 目标受众 | 谁在看 | 30-50岁实体老板 / 摄影爱好者 |
| 个人特点 | 人设标签 | 37岁重启 / 10年门窗老师傅 |
| 核心话题 | 今天聊什么 | 门窗选购 / 摄影技巧 / AI工具 |

## 话术生成矩阵

### 维度一：直播阶段（横向）

| 阶段 | 时间 | 任务 | 用户状态 |
|------|------|------|---------|
| 开场破冰 | 0-5min | 等人进、打招呼、建立第一印象 | 刚刷到，决定留不留 |
| 内容输出 | 5-20min | 输出价值，讲干货/故事 | 开始听，判断有没有用 |
| 互动留人 | 20-40min | 问答、福袋、话题讨论 | 开始参与，停留加深 |
| 转化收尾 | 40-60min | 引导关注/加粉/下单/下播预告 | 决定要不要关注/买 |

### 维度二：话术类型（纵向）

| 类型 | 特征 | 使用时机 |
|------|------|---------|
| 自我介绍型 | 我是谁、我为什么在这、我能给你什么 | 开场/新观众不断进来 |
| 干货输出型 | 具体方法、技巧、经验 | 内容输出阶段 |
| 故事分享型 | 真实经历、客户案例 | 建立信任/情感链接 |
| 互动引导型 | 提问、投票、点名 | 提升互动率/停留时长 |
| 应对黑粉型 | 接话、化解、反转化 | 全程 |
| 转化引导型 | 关注、点赞、下单 | 收尾阶段 |
| 应急兜底型 | 冷场、没人说话、设备问题 | 全程备用 |

### 交叉矩阵

```
每个阶段 × 每种话术类型 = 至少1条话术

开场破冰：
  × 自我介绍型 → 1条
  × 互动引导型 → 1条
  × 故事分享型 → 1条

内容输出：
  × 干货输出型 → 2条
  × 故事分享型 → 1条
  × 互动引导型 → 1条

互动留人：
  × 互动引导型 → 2条
  × 应对黑粉型 → 1条
  × 干货输出型 → 1条

转化收尾：
  × 转化引导型 → 2条
  × 故事分享型 → 1条
  × 自我介绍型 → 1条

应急兜底：
  × 应急兜底型 → 3条
```

合计：约20条话术，覆盖整场直播。

## 口语化铁律

每条话术必须通过以下检查：

```
✅ 像一个人在对另一个人说话（不是念稿）
✅ 有语气词（吧、吗、啊、了、的、哈、呗）
✅ 有问句/感叹句/反问句（制造互动感）
✅ 有具体场景和画面（让人能想象）
✅ 字数在15-50字之间（一句话能说完）
✅ 有节奏感（短句为主，偶尔长句）

❌ 书面语、新闻体、排比句
❌ 没有信息量的大白话
❌ 太长（超过50字一句）
❌ 太短（连续短句像电报）
```

### 口语化对照表

| 书面化 ❌ | 口语化 ✅ |
|---------|---------|
| 「欢迎各位来到我的直播间」 | 「欢迎刚进来的朋友，还没走说明咱们有缘分啊」 |
| 「今天给大家分享门窗选购技巧」 | 「今天聊聊买门窗怎么不被坑，都是我自己踩过的坑」 |
| 「请各位点赞关注」 | 「觉得有用的话点个赞，不要钱不点就亏了哈哈」 |
| 「感谢大家的支持」 | 「谢谢大家，就冲你们这份支持，今天必须把干货掏出来」 |
